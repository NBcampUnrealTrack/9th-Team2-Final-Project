# 9th-Team2-Final-Project

🎮 **[프로젝트 이름 : Last Check-Out]**  
Unreal Engine 5.8 기반의 1인칭 심리 서바이벌 호러 / 추리 어드벤처 게임입니다.

## 1. 프로젝트 개요 (Overview)

**장르:** First-Person Psychological Survival Horror / Investigation  
(1인칭 심리 서바이벌 호러 / 추리 어드벤처)

**플랫폼:** Windows

**개발 엔진:** Unreal Engine 5.8

**개발 언어:** C++

**대상 플레이어:**  
고난도 조사 및 추론 퍼즐과 서바이벌 호러 장르를 선호하는 게이머

**예상 플레이 시간:**  
약 4 ~ 6시간

---

## 2. 프로젝트 목표

추리와 공포가 자연스럽게 결합된 게임 플레이를 구현하는 것을 목표로 합니다.

플레이어는 단순한 사건 조사를 시작으로 호텔에 숨겨진 단서를 하나씩 발견하고,  
과거의 사건을 직접 재현하며 사건의 진실에 접근하게 됩니다.

단서를 수집하고 추론하는 **조사 과정**과  
추격자를 피해 살아남아야 하는 **서바이벌 요소**를 결합하여  
긴장감 있는 게임 플레이를 구현하고자 했습니다.

---

## 3. 게임 특징 (Game Features)

### 🔎 사건 조사

호텔 곳곳에 숨겨진 단서와 증거를 조사하며 사건의 진실을 추적합니다.

### 🕰️ 과거의 현장 재현

회사에서 지급받은 특수 장비를 활용하여  
현재의 공간에서 과거에 발생했던 사건의 현장을 재현합니다.

### 🧩 추리 및 퍼즐

수집한 단서와 주변 환경을 분석하여 사건의 흐름을 추론하고  
퍼즐을 해결하며 다음 사건으로 진행합니다.

### 👁️ 심리적 공포

갑작스러운 공포 연출뿐만 아니라  
알 수 없는 존재와 폐쇄적인 호텔 공간에서 느껴지는 심리적 압박감을 중심으로 공포를 연출합니다.

### 🏃 서바이벌

조사를 진행하는 과정에서 플레이어를 위협하는 추격자가 등장하며,  
추격을 피해 안전한 장소로 이동하고 탈출해야 합니다.

---

## 4. 한 줄 요약

> 단순 실족사 조사를 위해 파견된 보험조사관이 회사에서 지급받은 특수 장비로
> '과거의 현장'을 재현하며 호텔에 숨겨진 참극에 휘말리고,
> 추격자의 위협을 피해 탈출하는 심리 서바이벌 호러.
